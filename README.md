# Global Airline Route Network Analysis

This project analyzes the structure of the global commercial aviation network — airports, airlines, and the routes connecting them — using Excel for data cleaning and Power BI for interactive visualization.

As someone transitioning from a Software Engineering background into aviation operations (currently working in Operations at Dublin Airport with SSP), I built this project to apply data analysis skills to a domain I'm actively working to move into professionally: aviation operations, flight data analytics, and airline network planning.

**Data source:** [OpenFlights](https://openflights.org/data.php) — 
A free, open dataset covering ~7,000 airports, ~6,000 airlines, and ~67,000 routes worldwide. Note: this is a static snapshot last properly updated around 2020, so it reflects network *structure* (which airports connect to which) rather than live/current performance data.

**Tools used:** Microsoft Excel (data cleaning, Power Query, pivot tables) and Power BI 
(data modeling, DAX measures, interactive dashboard).

**Key questions explored in 2 dashboards:**

Dashboard 1

1. Which countries have the most airports in the dataset? (Bar Chart Analysis)
2. Which airports have the most outbound routes?
3. Which countries have the most airports in the dataset? (Pie Chart Analysis)
4. Where are all airports located globally?
5. Which airlines operate the largest route networks?
